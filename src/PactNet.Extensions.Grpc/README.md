# PactNet.Extensions.Grpc

A fluent wrapper for unary gRPC Pact V4 interactions using the Pact protobuf plugin.

This package depends on the synchronous plugin API from PactNet PR #551, which
is not yet merged. Local builds use a pinned prerelease dependency, not a
published supported PactNet version. Do not publish these bootstrap packages.

See https://github.com/pact-foundation/pact-net-extensions for setup, samples,
wrapper-author guidance, and independent package release instructions.
